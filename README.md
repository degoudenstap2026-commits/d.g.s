# De Gouden Stap — bedrijfswebsite

Dit is een bedrijfswebsite en geen webshop.

## Inhoud
- Homepagina van De Gouden Stap
- Over ons
- Productencollectie met afbeeldingen
- Zoekfunctie
- Categorieën
- Contactgedeelte
- Responsive ontwerp voor mobiel en desktop

## Aanpassen
- `products.js` → productnamen, categorieën en afbeeldingen
- `index.html` → teksten en pagina-opbouw
- `style.css` → kleuren, lettertypes en vormgeving
- `script.js` → zoekfunctie en productweergave

Er staan bewust **geen prijzen en geen winkelmandje** op de website.
